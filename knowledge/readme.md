# Premissas do Projeto

## Comparativo de Equipamentos

O objetivo principal deste projeto é analisar a eficiência e o impacto de um novo equipamento de climatização instalado no **aviário 1283**.

O **aviário 1282** serve como grupo de controle, operando sem o novo equipamento.

As análises comparativas entre esses dois aviários são fundamentais para avaliar o desempenho e o retorno sobre o investimento do equipamento em teste.
